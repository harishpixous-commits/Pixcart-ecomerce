# PixCartWeb (Angular 21)

The PixCart storefront, seller hub, delivery partner app and admin panel, ported pixel for pixel from the reference
Next.js app (`frontend/` on `main`). Read `docs/PORTING_GUIDE.md` first.

## Run

```bash
npx -y npm@11 install
npx ng serve            # http://localhost:4201, /api and /media proxied to http://localhost:8100 (proxy.conf.json)
npx ng build
```

## Where things are

| Path | What |
|---|---|

| `src/app/shared/ui/` | `ui.ts` (Button, ButtonLink, Field, Input, TextField, Select, Textarea, Spinner, Price, Rating, Pill, StatusPill, EmptyState, ErrorNote, Pagination, Modal, Toast, ProductImage), `skeletons.ts`, `page-loader.ts`, `icon.ts`, `link.ts`, `cx.ts` |

| `src/app/shared/shop/` | shop header parts (logo, account menu, deliver-to, cart link, search box, All menu, nav bar) |

| `src/app/shared/admin-shell/`, `shared/portal-shell.ts`, `delivery/shell/` | panel shells |

## Porting a page (other modules)

1. Find the placeholder: `/orders/:id` is `src/app/shop/pages/orders-id.page.ts` (`ShopOrdersIdPage`); the route map is
   `src/app/shop/shop.routes.ts`. Replace the component in that file and keep the class name, so the routes need no change.
2. Port the `.tsx` with the same markup, classes, texts and `data-testid`s. Conversions:
   - `<Link href>` → `<a pcLink="/path?x=1">`; `router.push(x)` → `inject(Router).navigateByUrl(x)`; `router.replace` → `{ replaceUrl: true }`
   - `usePathname()` / `useSearchParams()` → `inject(RouteState).pathname()` / `.param("q")`; route params also arrive as component inputs
   - `useSession()` → `inject(SessionService)` (signals `user()`, `ready()`, `cartCount()`; `signIn`, `signOut`, `addToCart`)
   - `useSite()` / `useLists()` → `inject(SiteService).site()` / `.lists()`; `useLayout()` / `useTheme()` → `inject(ThemeService).layout()` / `.active()`
   - `useToast()` → `inject(Toast).show(text, "error")`; `useAdmin()` / `useCan(p)` → `inject(AdminContext).me()` / `.can(p)`
   - lucide icons → `<svg [pcIcon]="Truck" class="h-5 w-5" />` (import from `lucide-angular`; `Home` is `House`)
   - `clsx(...)` → `cx(...)`; `{cond && <X/>}` → `@if`; lists → `@for (...; track id)`
   - `PageLoader variant="list"` → `<pc-page-loader variant="list" />`; skeletons → `shared/ui/skeletons.ts`
   - product lists → `<pc-product-grid [items]>`, `<pc-product-rail title [items] href>`, or `<pc-grid-frame>` + `<ng-container [pcProductTile]="p" />`
   - seller/admin pages → `<pc-page-header title sub [back]>` (actions marked `actions`), `<pc-tabs>`, `<pc-stat>`, `<pc-table [head]>`
3. Hosts: a component's host element sits in the DOM. Use `host: { class: "contents" }` when the reference has no element
   there, or make the host the root element (its classes in `host`). CSS child selectors (`[&>*]`, `space-y-*`,
   `divide-y`, `first:`) see the real DOM.
4. Check with `node ../tools/parity/compare.cjs --routes /your/route --themes classic,bazaar,fresh,luxe`.
